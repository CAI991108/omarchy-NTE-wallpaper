壁纸画廊

预览、单张下载，或者用 install.sh --wallpapers 一次装进 omarchy-NTE。

还没有壁纸。把图放进 wallpapers/<theme>/，运行 scripts/build.sh。

装进 Omarchy

cd ~/omarchy-NTE
./install.sh --wallpapers             # 当前主题
./install.sh --wallpapers=catppuccin  # 指定主题

装完按 Super + Ctrl + Space（Omarchy 3.8.2； 4.x 是 Super + Ctrl + W）挑选壁纸。

手动安装：把文件放进 ~/.config/omarchy/backgrounds/<主题>/。

壁纸版权归原作者/发行方所有，来源见 CREDITS；代码 MIT。 这个页面是纯静态的，数据来自 manifests/wallpapers.json。
